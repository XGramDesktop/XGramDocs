GETTING STARTED

Установка XGram Desktop

Загружайте приложение только со страницы официальных релизов XGram.

Windows

  1. Откройте Releases.
  2. Скачайте актуальный файл XGram.exe из нужного релиза.
  3. Запустите файл и завершите вход в Telegram в самом приложении.
Не передавайте коды входа, пароль двухэтапной проверки и папку данных третьим лицам.

Обновления

Перед заменой приложения полностью закройте XGram. Не удаляйте локальную папку данных, если хотите сохранить авторизации.
