Установка XGram Desktop

Готовые сборки для Windows x64 публикуются в официальном репозитории XGramDesktop.

Скачать и запустить

  1. Открой официальные релизы XGram Desktop.
  2. Выбери релиз и скачай файл для Windows x64 из блока Assets. Например, в релизе v1 он называется XGram-v1-Windows-x64.exe. Архивы Source code содержат исходники.
  3. Помести приложение в отдельную папку и запусти скачанный файл.
  4. Войди через интерфейс Telegram в самом приложении. После входа открой XGram Preferences.

Обновления

Перед обновлением полностью закрой XGram, включая значок в области уведомлений Windows. Сделай резервную копию локальной папки данных, затем замени исполняемый файл новой сборкой.

Не удаляй локальные данные, если хочешь сохранить авторизации. Храни резервные копии в защищённом месте; подробнее — в руководстве по данным.

Другие платформы и сборка из исходников

Здесь описана установка готовой Windows-сборки. Инструкции для разработчиков находятся в репозитории: Windows, Linux, macOS. Наличие инструкции не означает, что для платформы опубликован готовый релиз.

Если приложение не запускается

Проверь, что скачан исполняемый файл для Windows x64. В отчёте об ошибке укажи версию Windows, версию XGram и шаги до появления проблемы. Не прикладывай папку tdata или файлы авторизации.
